# 使用说明

研知 Research 把问答、深入研究和实验核验放在同一个工作台。三种任务共用账户、模型预设、资料库和左侧历史记录。

## 从问题开始

- **快速问答**：由所选模型直接回答，适合解释概念、阅读资料或继续讨论。每次只发起一次回答请求，可按需联网。
- **深度研究**：先制定计划，再分工查找资料、检查结论并生成报告。左侧可以设置协作人数和派生层级。
- **实验核验**：把论文中的实验与自己的运行结果放在一起，检查使用的数据、模型、评估方法和结果是否可以比较。

先在“模型预设”保存支持 Responses API 的模型，然后在输入框或核验页面选择。资料库中的文件只有处理完成后才可使用。模型密钥只在服务端解密使用，不会回传给浏览器。

应用不再为一次研究设置模型请求次数、搜索次数、工具调用次数或累计 token 配额。用量仍会记录；服务商自己的限流和额度仍然适用。研究仍有超时、并发与协作规模约束，也可以主动停止。

## 核对论文和实验结果

1. 选择“实验核验”，上传论文或从资料库选择已有文件。
2. 上传实验运行摘要，也可以直接粘贴结果并保存为资料。无需上传模型权重、实验代码或整个数据集。
3. 输入要核对的指标。如果论文里有多个模型、多个表格，请写清模型名和表号，例如“ResNet-50，Table 3，top-1 error”。选择模型后生成核验结果。
4. 检查模型整理的内容。逐项查看两份资料中的原文，必要时修改内容或引用；确认正确的项目，对无法判断的项目标记为未解决。
5. 全部检查后确认并保存。已确认的记录只读，仍然可以重新打开查看。

运行摘要示例（数值仅用于演示）：

```text
模型：ResNet-50
数据集：ImageNet
数据划分：validation
评估方式：10-crop
指标：top-1 error
结果：24.10%
随机种子：42
```

支持 TXT、Markdown、CSV、DOCX 和可提取文字的 PDF。论文和运行摘要必须是两份不同的资料。整理两份资料最长等待 120 秒，期间可以取消；目标描述最多 120 字，超长时会提示。

## 如何理解核验结果

“一致”表示资料中有可核对的原文，且两边在这一项上没有发现差异；“不一致”表示发现了明确差异；“无法判断”表示缺少信息、原文不能证实或比较条件不足。相同的数值不等于实验已经复现。

系统会检查数据集及版本、数据划分、模型、训练方式、评估方法、指标、数值、单位和随机种子。论文未说明的内容不会要求模型补写。指标不同或无法确认时，不直接比较数值；百分数的不同写法可以统一，但不会自动把 0.407 换算成 40.7%。

点击“查看原文”可以打开资料中的相关片段。引用不准确时，可以在这份资料里搜索、更换原文并修改摘录；保存时会再次检查引用是否确实来自所选资料。PDF 摘录只在能够唯一匹配某一页时显示页码。暂不支持扫描件识别、表格单元格定位，也不能自动保证模型选中了正确的实验行。

## 历史与继续研究

左侧历史同时包含问答、深度研究和实验核验，可搜索标题、重命名和删除。打开待检查的核验记录可以继续修改；已确认记录保持只读。“带着这两份资料继续研究”会新建问答，并选中同一份论文和运行摘要。

删除历史记录会同时删除关联的消息或核验结果，资料库中的文件保留。删除资料后，历史核验里保存的摘录仍可查看，但对应原文可能无法重新打开。

问答和深度研究与当前连接绑定，离开页面或断开连接会取消，暂不支持服务重启后续跑。连接错误时先保存已有内容，再检查服务状态和模型设置，避免反复提交相同请求。
