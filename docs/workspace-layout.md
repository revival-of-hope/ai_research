# 工作台布局调整

日期：2026-10-18。按用户最新要求，将模式和深度研究设置移入侧栏，扩大内容展示空间，保留原有浅色、slate 与蓝色视觉语言。

## 官方竞品调研与取舍

- [ChatGPT 深度研究](https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt)：官方支持从侧栏进入深度研究，并为长报告提供专门的阅读空间、目录、来源与活动记录。本项目采用侧栏集中入口、主区域专注阅读的方向，保留已有目录、来源和导出行为。
- [Claude Artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them)：较完整的内容在对话旁的独立区域中呈现。本项目参考其控制区与内容区分离的思路；保持现有单个对话阅读区，避免新增面板占用宽度。

这些是本项目的设计取舍，不表示照搬竞品页面或引入它们的产品能力。

## 实施

- 左侧保留原有 272px 导航，模式切换位于资料/模型入口下方、历史记录上方。深度模式的两个参数始终展开；快速模式只显示简要说明。
- 新增 `ResearchControls`，继续使用原有 hook 状态与回调；初始化、载入历史和生成中禁用控件。切换模式不清空草稿或协作参数。
- 移除输入框上方的大模式面板。输入框保留模型、联网、资料、发送和停止；新会话输入框由三行增加到四行，继续支持手动调整高度。
- 报告、输入框、空态和错误提示统一内容宽度上限 1360px。顶栏由 64px 减至 56px，底部仅保留输入区域，增加正文可视高度。
- 桌面正文由 15px 调为 16px，保留行距与章节层次；来源、表格、代码与导出逻辑保持原样。
- 手机标题栏显示当前模式，可直接打开原有侧栏。侧栏保留焦点约束、Escape 关闭及焦点恢复；短屏下内容可滚动，账户入口留在底部。

## 验证

- 前端 29 项测试通过，TypeScript / Vite 生产构建通过。
- 隔离 SQLite 与本地模型替身，不使用业务数据库或真实收费接口。
- 桌面 1440×900、1024×768，手机 390×844、横屏 844×390 检查；页面无整体横向溢出，短屏下可滚动访问参数与历史，账户入口可见。
- 在 1440×900 下，正文容器实测约 1089px，阅读区高 647px；更宽视口可继续增长至设定上限。
- 切换深度/快速保留草稿及参数；4 个智能体、2 层派生正确提交；快速问答仍为一个 medium 模型请求。生成期间参数锁定，刷新后历史恢复最近的回答模式。
- 验证手机 Tab 焦点循环、Escape 关闭和焦点回到模式入口。长报告保持章节、表格、代码、来源、复制与导出入口。
- 没有推送、部署或重启当前运行的项目容器。
