## 历史模型评估与适用范围

早期使用一个免费 Responses 网关完成过两组合成摘要测试，另一次论文请求返回 502。四个成功请求返回 24,581 tokens，加上兼容性探测共 33,827 tokens；两组合计模型耗时为 112.593 秒和 98.478 秒。只保留了通过本地检查的候选，无法由此计算全部原始模型引用的精确率；样本也不足以推断一般误判率。

2026-11-03 使用五篇论文和二十份合成运行摘要，按当时九项比较规则评估：

- 判断结果与人工答案匹配 123/180（68.33%）。在七十个应为“不一致”或“无法判断”的项目中，没有观察到错误的“一致”。
- 217 个通过本地原文检查并保留的结果都有可支持摘录；该比例不代表模型全部原始输出的引用精确率。
- 单请求 n=40，平均 16.264 秒，中位数 16.208 秒，nearest-rank p95 为 18.378 秒；每组两次请求合计平均 32.527 秒，p95 为 34.736 秒。
- 当时返回 173,576 输入 tokens（含 129,024 缓存命中）和 10,621 输出 tokens；原评估按当时价格估算约 USD 0.013442，属于历史估算，并非账户账单或当前价格。

评估存在论文信息漏读、类别混淆和多行表格选错的问题。运行摘要是合成测试材料，不代表真实训练复现。新增训练条件后的比较规则与旧评估不能直接混算。后续评估应固定样本、代码版本与模型，保留人工答案、完整原始输出、证据、耗时、用量及失败记录。

此前已通过 PostgreSQL 并发回归修复“旧的编辑请求覆盖已确认记录”，并补充百分数格式、指标与数值依赖、预训练来源、裁剪与分辨率、目标表格取证范围等确定性测试。旧样例矩阵中把不同指标的数值也期望为 mismatch 的表述已过时，当前规则统一为 unknown，避免把不可比指标直接比较。
